# FoodFlow (ফুডফ্লো) 🍃

A clean, modern, and minimal e-commerce website for authentic Bangladeshi organic foods.

## 🌿 Flagship Catalog
1. **FoodFlow Pure Milk Butter (খাঁটি দানাদার মিল্ক বাটার)**
2. **FoodFlow Premium Danadar Cow Ghee (গাওয়া দানাদার ঘি)**
3. **FoodFlow Arabica Roast Coffee (রোস্টেড কফি বিন)**
4. **FoodFlow Trio Breakfast Combo (৩-ইন-১ কম্বো)**

## 🚀 Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS + Lucide Icons
- **Currency & Market:** BDT (৳) with Cash on Delivery (COD) & bKash
- **Direct Order:** Automated WhatsApp 1-click ordering integration

## 🛠️ Local Development
```bash
./dev.sh
```
Open [http://localhost:3002](http://localhost:3002) in your browser.
